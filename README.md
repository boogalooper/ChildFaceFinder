# Child Face Finder

Child Face Finder помогает разобрать съёмку по людям: найти фотографии нужного человека, собрать их в отдельную папку или записать имена в метаданные для работы в Adobe Bridge.

Есть два сценария: **поиск по подписанным эталонам** и **поиск уникальных лиц без эталонов**. Программа подходит для детей и взрослых, портретов и групповых фотографий.

Обработка выполняется **локально**. Фотографии никуда не отправляются.

---

# Что умеет программа

- Искать людей по одному или нескольким эталонам.
- Объединять фотографии одного человека без заранее подготовленных эталонов.
- Создавать список найденных фотографий в CSV.
- Копировать или перемещать фотографии в папки людей вместе с внешними XMP.
- Записывать найденных людей в метаданные.
- Определять серии и отмечать лучшие кадры цветом.
- При необходимости исключать неудачные кадры из результата.

**Важно:** исходники зависят от выбранного действия. Копирование сохраняет оригиналы, перемещение удаляет их после проверки копий, а включённая запись XMP меняет метаданные.

# Установка и запуск

## Первая установка

Программа рассчитана на **64-битную Windows** и NVIDIA GPU с подходящим драйвером. Для первой установки нужен интернет.

1. Распакуйте архив в отдельную папку, например `F:\AI tools\ChildFaceFinder`.
2. Запустите `install.bat`.
3. Дождитесь успешного завершения установки.
4. Запустите `run.bat`.

Системный Python и отдельная установка CUDA Toolkit не нужны. Программа устанавливает собственное окружение и необходимые модели.

Для обычной работы используйте **`run.bat`**.

## Обновление установленной программы

1. Закройте программу.
2. Распакуйте новый архив поверх установленной версии с заменой файлов.
3. Сохраните имеющиеся папки окружения, инструментов и моделей.
4. При обновлении с версии без встроенного XMP один раз запустите **`update_metadata.bat`**.
5. Запустите `run.bat`.

`update_metadata.bat` устанавливает только компонент записи встроенного XMP. Повторно скачивать модели для этого не нужно. При новой установке этот компонент уже устанавливается через `install.bat`.

# Быстрый старт

Главное окно состоит из четырёх блоков:

| Блок | Что выбрать |
|---|---|
| **1. Что найти** | Людей по эталонам или уникальные лица |
| **2. Исходные фотографии** | Папку съёмки и, если нужны, эталоны |
| **3. Как сохранить результат** | CSV, папки людей или только метаданные |
| **4. Метаданные — необязательно** | Запись людей и/или цветовые метки |

После выбора нажмите **«Начать обработку»**.

Начните с рекомендуемых настроек. Кнопка **«Настройки…»** нужна, если требуется изменить качество отбора, строгость распознавания, производительность или название цветовой метки.

# Сценарий 1. Найти людей по эталонным фотографиям

Подходит, если у вас есть подписанные фотографии людей и нужно найти их во всей съёмке.

1. Выберите **«Людей по эталонным фото»**.
2. Укажите папку **«Эталонные фото»**.
3. Укажите папку **«Фото съёмки»**.
4. Выберите результат: **«Список CSV»** или **«По папкам людей»**.
5. При необходимости включите XMP.
6. Нажмите **«Начать обработку»**.

Имена в результате берутся из названий эталонных файлов.

## Как подготовить эталоны

Используйте чёткие фотографии, на которых хорошо видно лицо нужного человека. Удобнее всего — отдельные портреты.

Примеры названий:

```text
Котов Никита.jpg
Балаева Виктория.jpg
Smith John.jpg
```

Для одного человека можно подготовить несколько эталонов с разными ракурсами. Например:

```text
712 Котов Никита.jpg
709 Котов Никита.jpg
```

Начальный номер с пробелом отбрасывается: оба файла относятся к **Котов Никита**. Аналогично обрабатываются одиночные заглавные латинские индексы: `A Котов Никита.jpg`, `B Котов Никита.jpg`.

Можно хранить одинаково подписанные эталоны в разных подпапках. Подпапки эталонов просматриваются автоматически.

**Не подписывайте разных людей одинаковым именем:** имя используется как идентификатор человека.

Папки съёмки и эталонов должны различаться. Если папка эталонов находится внутри съёмки, она исключается из анализа фотографий съёмки.

---

# Сценарий 2. Найти уникальные лица без эталонов

Подходит, если подписанных портретов нет, а фотографии нужно разделить по людям.

1. Выберите **«Уникальные лица в съёмке»**.
2. Укажите **«Фото съёмки»**.
3. Выберите **«По папкам людей»**, затем папку результата и **«Копировать»**.
4. Если нужны имена для фильтрации в Bridge, включите запись людей в XMP.
5. Нажмите **«Начать обработку»**.

Программа назначает условные обозначения:

```text
Лицо_0001
Лицо_0002
Лицо_0003
```

Одному распознанному человеку на разных кадрах присваивается одно обозначение. Настоящее имя без подписанных эталонов программа не определяет.

В папке съёмки сохраняется `ChildFaceFinder_people.json` — каталог идентификаторов. Он помогает сохранять обозначения при повторном анализе той же папки. Для разных съёмок одинаковый номер не означает одного и того же человека.

Это не кэш фотографий: при новом запуске изображения анализируются заново.

# Как сохранить результат

## Список CSV

Создаёт таблицу людей и найденных фотографий. Один групповой кадр может встречаться в нескольких строках — по одной на каждого найденного человека.

В таблице также есть признак лучшего кадра для человека, если включён выбор лучших, и причины замечаний к качеству.

Файл записывается в UTF-8 с разделителем `;`. Если Excel не разделил его на столбцы, импортируйте файл как текст/CSV с этим разделителем.

Дополнительные отчёты о браке, сомнениях и лучших кадрах включаются отдельно в **«Настройки → Вывод и XMP»**.

## По папкам людей

Создаёт папку для каждого человека и помещает туда найденные фотографии. Переносятся **полные фотографии**, не вырезанные лица.

Выберите способ:

| Способ | Что происходит с исходниками |
|---|---|
| **Копировать** | Оригиналы остаются в папке съёмки |
| **Переместить** | Оригиналы удаляются после проверки всех предназначенных им копий |

Если в кадре несколько людей, он попадает в папку каждого из них. Это относится и к перемещению: групповой кадр сначала копируется во все нужные папки, затем удаляется из исходной.

Существующий внешний XMP копируется или перемещается вместе с фотографией, даже если изменение метаданных выключено. Встроенный XMP переносится внутри изображения.

Дополнительные правила:

- Папка результата должна быть отдельно от съёмки и эталонов — не внутри них и не над ними.
- Совпадение имён не приводит к перезаписи: добавляется суффикс, одинаковый для фото и XMP.
- Фотографии без уверенно найденных людей остаются на месте.
- При включённом отборе качества не прошедшие его фотографии также могут остаться на месте.
- Ошибка обновления XMP блокирует перемещение соответствующего снимка.
- Если у нескольких изображений общий внешний XMP, их перемещение пропускается с сообщением в журнале.

CSV в этом режиме не создаётся. В папке результата сохраняется журнал операций `ChildFaceFinder_transfer_*.json`.

## Только анализ и метки

Используйте этот вариант, если хотите работать с исходной папкой в Bridge без CSV и раскладки файлов.

Нужно включить хотя бы одно действие XMP:

- запись найденных людей;
- цветовые метки лучших кадров.

Если оба действия выключены, запуск блокируется: сохранять результат некуда.

# Метаданные XMP

Общий переключатель **«Записывать метаданные XMP»** включает выбранные ниже действия. Если он выключен, метаданные не меняются.

Две опции независимы: можно включить одну или обе.

## Перезаписать список найденных людей

Записывает актуальный список уверенно распознанных людей на каждом успешно обработанном кадре:

- с эталонами — имена из эталонных файлов;
- без эталонов — обозначения `Лицо_0001` и далее.

Имена записываются в ключевые слова, иерархию `People|имя` и поле людей IPTC. Их можно использовать для поиска и фильтрации фотографий в Bridge.

Прежний список людей заменяется новым. Если на успешно проанализированном кадре никто не определён, прежние обозначенные имена людей очищаются. Обычные ключевые слова, которые не обозначены как люди, сохраняются.

Цветовые метки, рейтинг, настройки Camera Raw и другие данные эта опция не меняет. Старый служебный ключ `ChildFaceFinder|Best` удаляется при перезаписи людей; новые такие ключи не создаются.

**Качество кадра не равно уверенности распознавания.** Человек с закрытыми глазами может быть уверенно распознан и записан в XMP, даже если фотография исключена из папки результата фильтром качества.

## Определить серии и отметить лучшие кадры цветом

Выбирает лучший кадр человека в каждой определённой серии и назначает ему цветовую метку.

**Прежние цветовые метки успешно обработанных фотографий заменяются:** лучшие кадры получают выбранную метку, у остальных метка очищается. Звёздочный рейтинг не меняется.

Без включения записи людей список людей не изменяется.

У групповой фотографии только одна цветовая метка. Кадр отмечается, если он лучший **хотя бы для одного человека**. Это не означает, что на нём лучше всего получились все участники. Для кого именно кадр выбран лучшим, можно увидеть в CSV.

## Как настроить цвет в Bridge

1. Откройте **«Настройки → Вывод и XMP»**.
2. Введите **название метки**, используемое в ваших настройках Bridge.
3. Либо нажмите **«Взять название из готового XMP…»** и выберите внешний XMP фотографии с нужной цветовой меткой.

Исходное значение — `Select`. Если название не совпадает с настройками Bridge, ожидаемый цвет может не отображаться. Кнопка считывания принимает именно внешний `.xmp`, а не JPG со встроенными метаданными.

## Куда записывается XMP

| Формат | Место записи |
|---|---|
| JPEG, TIFF, DNG, PNG, WebP, PSD, JPEG 2000 | Внутрь файла при размере менее 1 ГБ |
| Камерные RAW: CR2, CR3, NEF, ARW и другие | Во внешний файл с тем же именем и расширением `.xmp` |
| Неподдерживаемые контейнеры, включая PSB; файлы от 1 ГБ | Во внешний XMP |

Для встроенной записи изображение не пересжимается. Изменения сначала сохраняются во временную копию, затем она заменяет исходный файл.

Внешний XMP для формата, который Adobe ожидает читать со встроенными метаданными, может не отображаться в Bridge. Особенно учитывайте это для крупных TIFF/PSD и PSB: текущая библиотека имеет ограничение встроенной записи.

Повреждённый JPG или ошибка встроенной записи не приводят к скрытому переходу на sidecar: операция сообщается как ошибка, оригинал сохраняется.

Старые внешние XMP рядом с JPG автоматически не импортируются и не удаляются: они могут принадлежать RAW с тем же именем. RAW и JPG с одинаковым именем получают новые метаданные раздельно: RAW — во внешний XMP, JPG — внутрь файла.

# Настройки

Окно **«Настройки…»** открывается по центру главного окна. **«Применить»** сохраняет изменения, **«Отмена»** возвращает предыдущие значения.

## Распознавание

| Параметр | Что меняет |
|---|---|
| **Поиск небольших лиц** | Режим поиска лиц, в том числе на групповых кадрах |
| **Порог обнаружения** | Насколько слабые кандидаты считаются лицами; снижение может добавить ложные обнаружения |
| **Порог совпадения** | Допустимое различие лиц; меньше значение — строже распознавание |
| **Отрыв от другого человека** | Насколько лучший кандидат должен отличаться от второго; увеличение делает выбор осторожнее |

Если результат устраивает, эти параметры менять не нужно.

## Отбор кадров

Переключатель **«Исключать неудачные кадры из CSV и папок людей»** определяет, применять ли фильтр качества к результату.

Можно учитывать закрытые глаза, нерезкость, поворот головы, размер лица, экспозицию и обрезание головы. Общая строгость задаётся пресетом.

При включённом отборе неудачные кадры исключаются также из выбора лучших. На запись уверенно найденных людей в XMP этот фильтр не влияет.

При переключении сценария на поиск по эталонам отбор включается, на поиск уникальных лиц — выключается. При необходимости измените это в настройках.

Если нужны **все фотографии человека**, выключите отбор качества. Если нужны только подходящие кадры — включите его.

## Производительность

- **Потоки декодирования** — сколько файлов могут подготавливаться параллельно.
- **Параллельные GPU-сеансы** — число параллельных сеансов нейросети. Увеличение повышает расход памяти и не всегда ускоряет обработку.
- **Требовать NVIDIA CUDA** — не продолжать обработку без доступного GPU.
- **Подробный журнал по каждому фото** — дополнительные сведения для диагностики.

Для RTX 5090 исходная точка — 2 GPU-сеанса. При нехватке памяти уменьшите число сеансов до 1.

## Вывод и XMP

Здесь находятся название цветовой метки и дополнительные CSV-отчёты. Дополнительные CSV создаются только при основном результате **«Список CSV»**.

Кнопка **«Рекомендуемые значения»** возвращает стандартные расширенные настройки.

# Прогресс и отмена

Во время анализа отображаются счётчик и имя фотографии.

Перед копированием или перемещением прогресс сбрасывается и заполняется заново. Снимок считается завершённым после обработки всех предназначенных ему копий вместе с XMP.

**«Отмена»** останавливает обработку при ближайшей безопасной проверке. Уже выполняющийся вызов GPU или декодера должен завершиться, поэтому остановка может быть не мгновенной.

Уже сохранённые результаты остаются. Отмена не откатывает всю папку. Если копирование снимка во все нужные папки не завершилось, оригинал остаётся, но уже готовые копии тоже могут остаться в результате.

Фото и внешний XMP удаляются последовательно. При ошибке удаления одного из них проверенные копии уже находятся в папке результата; подробности записываются в журнал операций.

# Форматы и служебные файлы

Для анализа используются распространённые растровые форматы, HEIC/HEIF/AVIF и RAW, поддерживаемые установленными декодерами. Возможность прочитать конкретный файл зависит от его формата и содержимого. Поддержка записи XMP сама по себе не гарантирует возможность анализа изображения.

| Файл | Для чего нужен |
|---|---|
| `%LOCALAPPDATA%\ChildFaceFinder\settings.json` | Сохранённые настройки интерфейса |
| `ChildFaceFinder_people.json` в папке съёмки | Идентификаторы людей при работе без эталонов |
| `ChildFaceFinder_transfer_*.json` в папке результата | Журнал копирования или перемещения |
| `childfacefinder_install.log` | Журнал установки |
| `STABILITY_REVIEW.md` | Техническое описание проверок и ограничений |

Каталог ID не переносится автоматически в папки людей при перемещении фотографий. Для обычной работы читать технические файлы не требуется.

# Если результат не такой, как ожидалось

## Человек не найден

Проверьте, что эталон подписан правильно, а лицо достаточно хорошо видно. Попробуйте добавить другой качественный эталон того же человека.

Если теряются небольшие лица на групповых кадрах, проверьте режим поиска небольших лиц в настройках. Не повышайте порог совпадения сразу на большое значение: это увеличивает риск перепутать похожих людей.

## В папке человека не хватает фотографий, но в XMP он указан

Проверьте **«Исключать неудачные кадры из CSV и папок людей»**. Метаданные учитывают распознанного человека независимо от отбора качества.

## Один человек получил несколько ID

Без эталонов разные ракурсы или плохое качество лица могут разделить одного человека на несколько групп. Для более предсказуемых имён используйте подписанные эталоны.

## Перепутаны похожие люди

Проверьте эталоны. Уменьшите порог совпадения или увеличьте отрыв от другого человека. Более строгие настройки могут увеличить количество неопределённых лиц.

## Кнопка запуска недоступна

Проверьте пути и выбранный результат. Для режима **«Только анализ и метки»** нужно включить хотя бы одно действие XMP.

## В Bridge нет ожидаемого цвета

Проверьте название метки в **«Настройки → Вывод и XMP»** и соответствующее название в Bridge. Затем проверьте журнал: не было ли ошибки записи XMP или перехода на внешний XMP из-за ограничения размера.

## JPG не получает метаданные

Если программа сообщает об отсутствии `pyexiv2`, закройте её, запустите `update_metadata.bat` и повторите обработку. При другой ошибке сохраните текст из журнала.

## Файл не переместился

Проверьте журнал. Возможные причины: ошибка копирования, изменение исходника во время обработки, ошибка XMP или общий внешний XMP у нескольких изображений. Файлы без найденных людей не перемещаются.

## Программа не запускается

Запустите `run.bat` и прочитайте сообщение в консоли. Если окружение отсутствует или повреждено, повторите `install.bat`.

Для диагностики используйте `setup\run_console.bat`. При ошибке установки сохраните `childfacefinder_install.log`.

## Ошибка GPU или нехватка памяти

Проверьте драйвер NVIDIA. Уменьшите число GPU-сеансов и потоков декодирования. Если окружение CUDA повреждено, восстановите его через `install.bat`.

# Перенос программы

Папку программы можно перенести целиком на другой локальный диск. После переноса запускайте обычный `run.bat`: он проверяет окружение и при необходимости адаптирует его к новому пути.

При переносе на другой компьютер рекомендуется запустить `install.bat`. Пути к фотографиям и эталонам при необходимости выберите заново.

# Ограничения

Распознавание и автоматический выбор лучших кадров могут ошибаться. Сомнительное лицо не обязательно получит имя, а без эталонов один человек иногда разделяется на несколько ID.

Запись защищена для отдельного файла, но обработка всей папки не является одной операцией с полным откатом. Не редактируйте те же метаданные одновременно в другом приложении.

Условия использования кода программы и моделей могут отличаться. Для модели InsightFace `antelopev2` проверьте лицензию модели перед коммерческим использованием.
