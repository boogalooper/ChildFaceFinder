# Child Face Finder

**Child Face Finder** помогает найти нужных людей на большом количестве фотографий по заранее подготовленным эталонам.

Программа особенно удобна для школьной и групповой съёмки: вы указываете фотографии детей, выбираете папку со всей съёмкой и получаете список кадров, на которых найден каждый ребёнок.

Все фотографии обрабатываются локально на компьютере. **Оригиналы не изменяются и не удаляются.**

## Что умеет программа

- искать сразу нескольких людей;
- использовать несколько эталонов одного человека;
- находить маленькие лица на групповых фотографиях;
- исключать неудачные кадры по качеству;
- отдельно сохранять сомнительные совпадения для проверки;
- находить серии фотографий и выбирать лучший кадр;
- создавать CSV с результатами;
- автоматически собирать найденные фотографии по папкам;
- работать с обычными форматами, HEIC/HEIF/AVIF и RAW;
- запоминать основные настройки между запусками.

## Быстрый старт

### 1. Установите программу

Распакуйте архив в обычную папку, например:

```text
F:\AI tools\ChildFaceFinder
```

Запустите:

```text
install.bat
```

Установщик сам подготовит всё необходимое, включая собственный Python. **Системный Python и отдельная установка CUDA Toolkit не нужны.**

Для работы требуется 64-битная Windows, NVIDIA GPU с актуальным драйвером и подключение к интернету во время первой установки.

После успешной установки запускайте программу через:

```text
run.bat
```

### 2. Подготовьте эталоны

Создайте папку с фотографиями людей, которых нужно найти:

```text
Эталоны/
├─ Котов Никита.jpg
├─ Балаева Виктория.jpg
└─ Синичкина.jpg
```

Имя файла используется как имя человека в результатах.

Для одного человека можно использовать несколько эталонов. Например:

```text
Эталоны/
├─ портрет/
│  ├─ Котов Никита.jpg
│  └─ Балаева Виктория.jpg
└─ стоя/
   ├─ Котов Никита.jpg
   └─ Балаева Виктория.jpg
```

Подпапки можно использовать свободно — программа просматривает всю папку эталонов целиком.

### 3. Выберите папки и начните поиск

В интерфейсе укажите:

- **Папка эталонов**;
- **Папка фотографий**;
- нужные параметры качества.

Для первого запуска обычно достаточно оставить рекомендуемые настройки и нажать **НАЧАТЬ АНАЛИЗ**.

## Как называть эталоны

Самый простой вариант:

```text
Котов Никита.jpg
Балаева Виктория.jpg
```

Можно оставлять номер исходного кадра перед именем:

```text
712 Котов Никита.jpg
709 Котов Никита.jpg
```

Оба файла будут относиться к `Котов Никита`.

Также допускаются одиночные заглавные латинские индексы:

```text
A Котов Никита.jpg
B Котов Никита.jpg
```

`A` и `B` будут отброшены.

Обычные латинские имена сохраняются без изменений:

```text
Smith John.jpg
McDonald Anna.jpg
```

Если программа не может однозначно понять, какие эталоны относятся к одному человеку, она не будет угадывать и покажет сообщение.

## Несколько эталонов одного человека

Для одного ребёнка можно использовать несколько хороших фотографий с разным ракурсом или выражением лица.

Программа сравнивает найденное лицо со всеми эталонами и использует наиболее удачное совпадение. Это обычно повышает стабильность распознавания.

Если эталоны одного человека слишком сильно отличаются друг от друга, программа предупредит об этом в журнале — так можно заметить случайно неправильно подписанный файл.

## Поиск маленьких лиц

Есть три режима:

- **Быстрый** — для обычных портретов и сравнительно крупных лиц;
- **Улучшенный** — рекомендуемый режим для большинства съёмок;
- **Максимальный** — лучше ищет совсем маленькие лица, но работает медленнее.

Для первого запуска рекомендуется **Улучшенный**.

## Фильтр качества

Программа может отдельно оценивать качество лица каждого найденного человека.

Можно исключать кадры, где:

- глаза закрыты или сильно прищурены;
- лицо нерезкое;
- голова сильно повёрнута;
- лицо слишком маленькое;
- экспозиция плохая;
- голова обрезана или находится слишком близко к краю кадра.

Доступны пресеты **Мягкий**, **Нормальный** и **Строгий**. Для начала рекомендуется **Нормальный**.

Каждый критерий можно включать и выключать отдельно.

На групповой фотографии качество проверяется отдельно для каждого человека. Если один ребёнок моргнул, он может быть исключён, а остальные дети с этого же кадра останутся в основных результатах.

## Какие файлы создаются после анализа

Основной CSV содержит уверенно найденные хорошие кадры.

Дополнительно программа может создать:

- `*_rejected.csv` — человек найден, но кадр исключён фильтром качества;
- `*_review.csv` — сомнительное совпадение, которое лучше проверить вручную;
- `*_best.csv` — лучшие кадры из последовательных серий, если эта функция включена.

В результатах сохраняется путь к исходной фотографии, поэтому одинаковые имена файлов в разных подпапках не должны путаться.

## Серии и лучший кадр

Опция **«Определять серии фотографий и выбирать лучший кадр для каждой цели»** полезна при серийной съёмке.

Программа объединяет соседние кадры одного уже распознанного человека в серии и выбирает лучший кадр внутри каждой серии.

При выборе учитываются открытые глаза, резкость, уверенность распознавания и ракурс головы.

Основной CSV при этом остаётся полным. Лучшие кадры дополнительно записываются в `*_best.csv`.

## Сборщик фотографий по CSV

Кнопка **«Собрать файлы по CSV…»** автоматически создаёт папки по именам людей и копирует туда найденные фотографии:

```text
Результат/
├─ Котов Никита/
├─ Балаева Виктория/
└─ Синичкина/
```

Исходные фотографии **не удаляются и не перезаписываются**.

Если папка фотографий уже указана в основном окне, сборщик использует её автоматически.

Во время работы показывается прогресс. Кнопка **Отмена** останавливает индексацию или копирование; уже полностью скопированные файлы сохраняются.

Для сборки можно использовать и `*_best.csv`, если нужны только лучшие кадры из каждой серии.

## Поддерживаемые форматы

Поддерживаются распространённые форматы:

- JPEG / JPG;
- PNG;
- TIFF;
- BMP;
- WebP;
- HEIC / HEIF / AVIF;
- RAW: CR2, CR3, NEF, ARW, DNG, RAF, RW2, ORF и другие.

Временные рабочие файлы создаются в системной папке TEMP и автоматически удаляются.

## Рекомендуемые настройки первого запуска

Начните с этих значений:

- **Поиск маленьких лиц:** `Улучшенный`;
- **Порог детектора:** `0.18`;
- **Фильтр качества:** `Нормальный`;
- **Порог совпадения:** `0.45`;
- **Отрыв от второго ребёнка:** `0.04`;
- **Параллельные GPU-сеансы:** `2`;
- проверка глаз — включена;
- проверка резкости — включена;
- проверка поворота — включена;
- проверка маленьких лиц — включена;
- проверку экспозиции на первом запуске можно оставить выключенной.

Если настройки стали слишком сложными или результат ухудшился, нажмите **«Рекомендуемые значения»**. Это не затрагивает фотографии и уже созданные результаты.

## Перенос программы

Папку Child Face Finder можно переименовать или перенести целиком на другой локальный диск.

После переноса просто запустите `run.bat`. Программа проверит локальное окружение и при необходимости автоматически адаптирует его к новому пути. Повторная установка только из-за переименования папки обычно не требуется.

Если вместе с программой были перемещены папки с фотографиями или эталонами, выберите их новое расположение в интерфейсе.

При переносе уже установленной программы на **другой компьютер** рекомендуется один раз запустить `install.bat`.

## Если программа не запускается

Сначала запустите `run.bat` и прочитайте сообщение в консоли.

Если программа сообщает, что локальное окружение отсутствует или повреждено, запустите:

```text
install.bat
```

Для более подробной диагностики можно использовать:

```text
setup\run_console.bat
```

Установщик сохраняет журнал:

```text
childfacefinder_install.log
```

Если установка завершилась ошибкой, приложите этот файл при описании проблемы.

### Если установка не может скачать файлы

Установщик предлагает два режима соединения:

1. **Обычный защищённый режим** — рекомендуется.
2. **Режим совместимости с Kaspersky** — используйте только если обычный режим не работает из-за HTTPS-проверки.

### Если программа не видит NVIDIA GPU

Проверьте, что установлен актуальный драйвер NVIDIA и Microsoft Visual C++ 2015–2022 Redistributable x64.

Отдельно устанавливать CUDA Toolkit не требуется.

## Безопасность исходных фотографий

При обычной работе Child Face Finder:

- только читает исходные фотографии;
- создаёт CSV с результатами;
- при использовании сборщика копирует выбранные файлы в новую папку;
- не удаляет оригиналы;
- не перезаписывает оригиналы.

## Лицензия моделей InsightFace

Код программы и используемые модели могут иметь разные условия лицензирования.

Перед коммерческим использованием модели `antelopev2` рекомендуется проверить актуальные условия лицензии InsightFace и соответствующего model zoo.
